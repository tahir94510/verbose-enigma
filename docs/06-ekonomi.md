# 06 — Ekonomi **[TASLAK]**

Referans: LoL/ARAM. Son vuruş becerisi yok (gladyatör kendi dövüşür) → ARAM kuralı: kimin vurduğundan bağımsız, **görüş alanındaki** ölümler tam altın; uzak yoldaki auxilia ölümleri **%40**.

| Kaynak | Değer |
|---|---|
| Başlangıç | 600 |
| Pasif gelir | 30 / 10 sn (0:40'tan) |
| Auxiliarius / Sagittarius / Balista öldürme | 20 / 16 / 45 |
| Dış / iç specula yıkma | 250 / 300 (+200 ilk yıkan) |
| Gladyatör öldürme | 300 (üst üste ölümde azalır) |
| Merkez arena yaratığı | 80–150, ~2 dk'da yeniden doğar |

Manipulus başına 3×20 + 2×16 = 92 altın; her 3. dalgada Balista (+15 pay).
Hedef: 12–15 dk maçta ortalama toplam gelir ~7500 (≈ 3 efsanevi + biraz epik; 4 slot hepsini almaya izin vermez).
**Kontrol gerekli:** bkz. 09 — dalga gelirinin yeniden hesabı.
Gladyatör ölümünde yeniden doğma süresi oyun ilerledikçe uzar; ölüm serisi ödül azalması LoL'den.
